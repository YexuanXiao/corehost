# DPI / Text Antialiasing

## DPI

manifest 声明：

```xml
<dpiAware>true/pm</dpiAware>
<dpiAwareness>PerMonitorV2,PerMonitor</dpiAwareness>
```

渲染线程每帧：

```cpp
const auto dpi = ::GetDpiForWindow(window_);
text_.set_size(16.0f * dpi / 96.0f);
```

- 字体大小以 16 DIP 为基准；
- DPI 改变时重新创建 normal/bold `IDWriteTextFormat`；
- cell metrics 随之变化；
- atlas 清空并重新栅格化；
- grid 重新计算 columns/rows。

当前测试环境 DPI 为 96；进程 DPI awareness 已验证为 PerMonitorV2。

## Initial window size

- 默认客户区目标为 1200x720 DIP；
- `CreateWindowExW` 前按 `GetDpiForSystem` 预缩放；
- 创建后按实际 `GetDpiForWindow` 再校正一次；
- `AdjustWindowRectExForDpi` 计算非客户区；
- `WM_GETMINMAXINFO` 的最小尺寸也按 DPI 缩放。

## Antialiasing

`font.anti_alias`：

- `grayscale`（默认）；
- `cleartype`。

`font.rendering_mode` 直接使用 `DWRITE_RENDERING_MODE`，默认 `DWRITE_RENDERING_MODE_DEFAULT`；
实现层将 `DEFAULT` 解析为 `NATURAL` 后传给 `CreateGlyphRunAnalysis`。

`font.turning` 组合 `gamma` 与 `contrast`：

- `gamma_contrast`
- `gamma`
- `contrast`
- `none`

`gamma_contrast` 默认同时启用 gamma correction 和 grayscale enhanced contrast。

当前 atlas 是 R8 alpha；`cleartype` 虽然能选择 DirectWrite antialias mode，但还没有独立 RGB atlas 和 shader 采样路径。
