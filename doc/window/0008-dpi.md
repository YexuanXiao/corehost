# DPI / Text Antialiasing

## DPI

manifest 声明：

```xml
<dpiAware>true/pm</dpiAware>
<dpiAwareness>PerMonitorV2,PerMonitor</dpiAwareness>
```

渲染线程每帧：

```cpp
const auto dpi = ::GetDpiForWindow(window_);
text_.set_size(16.0f * dpi / 96.0f);
```

- 字体大小以 16 DIP 为基准；
- DPI 改变时重新创建 normal/bold `IDWriteTextFormat`；
- cell metrics 随之变化；
- atlas 清空并重新栅格化；
- grid 重新计算 columns/rows。

当前测试环境 DPI 为 96；进程 DPI awareness 已验证为 PerMonitorV2。

## Initial window size

- 默认客户区目标为 1200x720 DIP；
- `CreateWindowExW` 前按 `GetDpiForSystem` 预缩放；
- 创建后按实际 `GetDpiForWindow` 再校正一次；
- `AdjustWindowRectExForDpi` 计算非客户区；
- `WM_GETMINMAXINFO` 的最小尺寸也按 DPI 缩放。

## Antialiasing

当前使用 **无抗锯齿** 的 aliased 文本路径：

```cpp
DWRITE_RENDERING_MODE_ALIASED
DWRITE_TEXT_ANTIALIAS_MODE_GRAYSCALE
DWRITE_TEXTURE_ALIASED_1x1
```

`font.antialias` 选择四个组合：

- `aliased_contrast_alpha`
- `aliased_contrast`
- `aliased_alpha`
- `aliased_none`

前两者启用 grayscale enhanced contrast，后两者关闭；`contrast_alpha` / `alpha` 启用 alpha correction。atlas 仍是 R8 alpha，shader 采样后乘 quad tint。
