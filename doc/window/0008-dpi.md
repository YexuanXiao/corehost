# DPI / Text Antialiasing

## DPI

manifest 声明：

```xml
<dpiAware>true/pm</dpiAware>
<dpiAwareness>PerMonitorV2,PerMonitor</dpiAwareness>
```

渲染线程每帧：

```cpp
const auto dpi = ::GetDpiForWindow(window_);
text_.set_size(16.0f * dpi / 96.0f);
```

- 字体大小以 16 DIP 为基准；
- DPI 改变时重新创建 normal/bold `IDWriteTextFormat`；
- cell metrics 随之变化；
- atlas 清空并重新栅格化；
- grid 重新计算 columns/rows。

当前测试环境 DPI 为 96；进程 DPI awareness 已验证为 PerMonitorV2。

## Antialiasing

当前使用 DirectWrite 最直接的灰度抗锯齿：

```cpp
DWRITE_RENDERING_MODE_NATURAL
DWRITE_TEXT_ANTIALIAS_MODE_GRAYSCALE
DWRITE_TEXTURE_ALIASED_1x1
```

atlas 是 R8 alpha，shader 采样 alpha 后乘 quad tint。

没有实现 ClearType 3x1 RGB 路径；ClearType 需要单独的 RGB atlas 和着色器采样。
